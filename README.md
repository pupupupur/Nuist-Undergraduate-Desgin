# SAR 车辆目标检测系统

基于深度学习的 SAR（合成孔径雷达）图像车辆目标检测与识别系统。

## 项目简介
本项目拟采用 YOLO 系列目标检测网络，在公开 SAR 车辆数据集上进行训练，
实现 SAR 图像中车辆的位置检测与类别识别，并输出可视化检测系统。
